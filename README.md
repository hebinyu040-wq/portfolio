# 动态作品集网站雏形

这是一个无需安装依赖即可预览的响应式静态网站。

## 预览

直接双击 `index.html` 即可打开。也可以在本目录启动任意静态文件服务器。

## 后续替换内容

封面、简历和结束页已经根据 Figma 画板重建为可编辑网页结构，不再使用整张设计稿截图。主要素材位于 `assets`：

- `cover-background.png`：首页无文字背景
- `cover-motion.mp4`：首页动态背景，自动静音循环播放
- `resume-portrait.png`：简历人物照片
- `end-background.png`：结束页无文字背景

三个页面的文字和排版位于 `index.html`，对应样式与进场动效位于 `styles.css`。桌面端按 1920 × 1080 的 Figma 坐标同比例缩放，手机端使用独立的纵向响应式布局。

作品项目内容集中在 `content.js` 的 `projects` 中，可继续替换项目名称、分类、年份、职责、案例叙述与视觉色彩。

## 当前包含

- 四章节顺序：封面、个人简历、作品、结束封面
- 封面、简历和结束页由独立背景、图片与网页文字分层组成
- 章节切换时包含背景缩放与内容分层进场动效
- 封面视频离开视口后自动暂停，并支持系统“减少动态效果”设置
- 响应式页面与移动端菜单
- 明暗主题切换
- 项目分类筛选
- 项目详情弹层
- 滚动出现、视差、悬停倾斜与动态跑马灯
- 减少动态效果的系统无障碍适配
- 键盘操作与基础语义结构
